# Bounded nominal instance witness reference

HOST_REFERENCE_ONLY, not compiler evidence. The model consumes normalized, already-resolved typed facts with a five-part identity tuple (package, namespace, owner path, declaration kind, name/specialization). It walks the reachable instance obligation graph iteratively; same-kind inheritance only, exact callable signatures, effect subset, one slot per name/arity, no generic substitution or overload variance. The unique applicable trait default or exact owner local instance implementation must satisfy all obligations. A diamond visiting the identical origin counts once; distinct defaults are ambiguous unless a checked local implementation resolves them. Inherited concrete class methods, field contracts, behavioral implications and generic constraints are intentionally not modeled. Inputs are not source or independently authenticated linker evidence; do not use a model witness as an executable ABI. No persistent cache is introduced. The bounded limits are reference test limits, not normative language ceilings. Production compilers must implement equivalent checks with their own canonical types, visibility and ownership facts.

The accompanying fixtures are complete candidate source sets, with explicit selected paths and expected integer results or diagnostic families/no-artifact requirements. They are not syntax-validated or guest-executed. The namespace positive tests admission, not cross-file dispatch. No backend may promote its evidence based on reference tests. Compiler adapters must bind exact compiler/source trees, build commands, phase-specific results and actual guest execution.
