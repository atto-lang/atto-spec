# Verified Core implementation coverage

The exit criteria cover all six foundations on Java, LLVM, and .NET. Each additional Atto target needs its own executable evidence before it can claim the Verified Core profile. The [Verified Core RFC](https://github.com/atto-lang/atto-source.rs/pull/557) defines the proposed guarantees. This record tracks what has been exercised and what still needs to be established.

| Foundation | Current evidence | Completion criteria |
| --- | --- | --- |
| Ownership and borrowing | Atto has an [ownership and memory contract](../spec/04-ownership-and-memory.md) and [shared borrow fixtures](https://github.com/atto-lang/atto-common-source/tree/main/fixtures/borrow-ownership-v2). The protocol mailbox slice exercises detached scalar frames and rejection of retired actor identities. | Define the typed ownership and loan semantics and establish preservation and progress for admitted code. Cover use after move, overlapping mutable loans, escaping borrows, destruction on every return and failure path, loans across suspension, and exact-once resource settlement on transfer, rejected admission, failed dispatch, cancellation, and stop. Verify compiler rejection and actual lifetime behavior on each backend. |
| Refinements and dependent types | The [scalar profile](verified-core-refinements-v1.md) implements checked signed intervals, local relational facts, boundary checks, and function contracts in Java, LLVM, and .NET. | Specify the admitted value-indexed fragment, starting with bounded constant indices and index-dependent array or slice bounds. Check refinement and index judgments under exact arithmetic and control flow, including invalid witnesses, narrowing failures, arithmetic overflow, imported summaries, and preserved bounds through joins. Prove VC soundness for the admitted fragment and exercise it in each backend. General dependent types require a defined decidable checking fragment or checked explicit evidence. |
| Units of measure | The [concrete integer quantity profile](verified-core-quantities-v1.md) checks nominal dimensions, exact rational scales, arithmetic, and explicit conversions in all three compilers. Protocol payload schemas use the normalized units. | Establish static and dynamic preservation for the concrete numeric model. Check dimensional mismatches, aliases and identity across modules, non-integral conversions, overflow, and backend agreement. Add separately specified evidence for unit-polymorphic quantities and any affine, floating-point, or rescaling claims. |
| Relational parametricity | The RFC specifies a pure, total starting fragment for `<parametric T>` and identifies required relational rules for aggregates and callbacks. Checked relational contracts between integers are already in the scalar fragment. | Add compiler kinding and admission for `parametric` binders and prove the fundamental theorem of the logical relation. Exercise identity, aggregates, and polymorphic callbacks and reject type-dependent reflection, classification, identity, casts, and observable drop. Verify specialization preserves the relation. Effectful extensions require an explicit relation over outcomes and traces. |
| Effects, actors, and concurrency proofs | [Protocol declarations](verified-core-protocol-declarations-v1.md), [transition-only actor handlers](verified-core-protocol-handlers-v1.md), and [local mailbox execution](verified-core-protocol-mailbox-v1.md) cover scalar payloads, state-dependent edges, receipts, and stop ordering. | Integrate guest typed spawn and send, stage user fields and protocol state together, check invariants at creation and commit, and prove the staging effect restrictions, isolation, failure handling, restart authority, and transferred ownership. Refine the concurrent model against compiled traces. Report safety and liveness separately, with explicit fairness, delivery, failure, and exploration bounds for temporal claims. |
| Proof-carrying compilation | The shared [proof receipt tooling](https://github.com/atto-lang/atto-common-source/blob/main/docs/verification/CORE_STDLIB_PROOF_IR_V1.md) checks record consistency within its declared scope. The mailbox runners bind local execution evidence to fixture and native artifact digests where applicable. | Emit versioned obligations and results from each compiler and check them with an independent verifier. Bind source and dependency identity, semantics, toolchain and proof versions, trust approvals, proof and counterexample digests, checks retained at runtime, target, and artifact digest. Strict builds reject missing, unknown, refuted, runtime-only, or unapproved assumed obligations. Add preservation or translation-validation evidence for each claimed artifact, with mutation controls for stale or substituted proofs and artifacts. |

The shared conformance corpus contains 23 concrete quantity cases, 49 scalar refinement cases, 17 protocol declaration cases, and 17 protocol actor handler cases. The local mailbox fixtures separately exercise live host integration with compiled actor bindings. Record source and fixture commits and trees, compiler and target, invoked modes, executed cases, artifact digests, and authenticated run evidence when available. Keep unsupported profiles and failed or unexecuted checks visible. [Atto conformance policy](../spec/11-conformance.md)

The local mailbox execution record for 2026-11-23 covers the three compiler profiles with the same [conformance checkout](https://github.com/atto-lang/atto-platform-conformance/tree/d60da7beff81ea674da35101ca1371740405b37d) and [shared reference](https://github.com/atto-lang/atto-common-source/tree/b6429578c32f51e4ccb237f3244a81391f751409).

- Java JDK 25 executed 20 receipt checks and 24 stop races. [Compiler source](https://github.com/atto-lang/atto-source.java/tree/d78a0acd6fbce6e6c5e1acb60e71907d1a6a4d1d)
- LLVM arm64 macOS executed 21 receipt checks and 24 stop races in both the regular native build and the build with the host and runtime instrumented by ASan and UBSan. [Compiler source](https://github.com/atto-lang/atto-source.llvm/tree/7274801eeea0702162cbc8f65056974525499dce)
- .NET NativeAOT on macOS arm64 executed 20 receipt checks and 24 stop races. [Compiler source](https://github.com/atto-lang/atto-source.net/tree/fc99b5bc75df5faec903403351076fc36de31411)

The next implementation slice combines typed guest mailbox operations with staged actor fields, an invariant over a refined quantity, and join and stop behavior that discharges the ownership settlement obligations. Proof evidence for that slice can then use the shared verifier and exercise strict admission before broader proof-language, dependent index, parametricity, and temporal extensions. Completion requires the evidence in every row of the table.
