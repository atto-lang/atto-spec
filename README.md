# AttoLang Language Specification

This repository is the home of the **AttoLang** (formerly Oreslang) language specification.

The specification is being bootstrapped. The normative chapters and cross-backend conformance requirements will be introduced through reviewable pull requests. Until a chapter is accepted, it is a **draft design target**, not proof that any compiler or runtime implements it.

AttoLang is an actor-first, statically typed systems language with explicit ownership, structured concurrency, capability-scoped execution, data-oriented programming, and AOT-oriented compilation.

See the [AttoLang brand compatibility contract](https://github.com/ores-truffle-oreslang/oreslang-common-source/blob/main/contracts/v1/attolang-brand-compat-v1.json) for the `.atto` / legacy `.ores` migration policy.
