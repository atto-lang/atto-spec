# Typed serialization methods v1 — candidate
Status: DESIGN_ONLY_NOT_EXECUTED. This is a proposed source-level extension, not accepted grammar or a wire ABI. It supplements architecture/actor-data-codec-policy-v1.md and actor-data-codec-selection-v1.md without changing their existing trusted endpoint policy, DATA/CONTROL separation or legacy MessagePack framing.

## Public capability surface
Proposed opt-in: a nominal class or struct with Serializable and/or Deserializable derivation; enums and ADTs use stable variant tags. Interfaces and traits can require capabilities, but cannot be instantiated directly. Generic derivation requires proof for every reachable field of the closed specialization. Exact declaration attachment syntax (including `with Serializable, Deserializable`) is subject to grammar review. Never infer that arbitrary private fields are exportable: explicit projection/derive policy controls wire inclusion, excluding secret, transient and capability fields. Generated methods and custom overrides use existing callable signatures and return/effect checks; no runtime reflection, JIT, or mandatory GC.

Candidate logical signatures (not parse fixtures):
- to_json() -> Result<string, EncodeError>; to_json_bytes() -> Result<Bytes, EncodeError>
- to_message_pack() -> Result<Bytes, EncodeError>
- static from_json(string) -> Result<Self, DecodeError>; static from_message_pack(Bytes) -> Result<Self, DecodeError>
- serialize(codec) -> Result<Bytes, EncodeError>; static deserialize(Bytes, codec) -> Result<Self, DecodeError>
- serialize_into(writer, codec) -> Result<usize, EncodeError>; static deserialize_from(reader, codec) -> Result<Self, DecodeError>
- parameterless forms only if a reviewed type/library contract binds a default; no payload-driven codec fallback. CBOR/Protobuf later profiles; Protobuf requires stable numbered schema. Existing library types may use different error/size aliases; reconcile rather than adding keywords. Pure encoders do not suspend; streaming I/O APIs explicitly declare suspension when needed.

## Compiler lowering and ownership
Generate closed, type-checked codec plans from nominal typed IR, preserving stable external field names/IDs independently of physical layout. No raw memory dumps, padding leakage, pointer values, dynamic class loading, or type-name lookup from untrusted data. Custom codecs are checked against the declared schema and trusted registry; they cannot bypass resource/authority admission. Polymorphic decode requires a closed, trusted discriminator-to-concrete-type mapping and an admitted constructor/invariant path. Unsupported cycles fail closed in v1; a separately ratified graph profile is not implied. Borrowed input remains immutable and lifetime-bound; returned owned values belong to the receiver arena, with rollback on every failed decode. Local Sendable proof is separate from format-specific serialization; ownership-safe move, frozen sharing or independent copy may avoid wire encoding. Never cross actor heap boundaries with raw pointers or mutable aliases. ActorRef and other authority-bearing handles remain forbidden under the initial DATA profile; future logical-reference resolution needs separate approval.

## Wire and resource policy
First portable profile: strict UTF-8 JSON and explicitly versioned MessagePack, with exact scalar ranges, string handling and schema field policy defined by shared vectors. JSON object duplicate keys, unknown discriminators, malformed UTF-8, overflow, nonfinite floats, trailing bytes, missing required fields and excessive depth/size/work must fail closed in the initial strict profile. Unknown optional fields and schema migration require explicit versioned policy. Charge cumulative input bytes, nodes, allocation, expanded bytes and work before materialization; do not reset meters in preflight, custom callbacks or nested fields. On failure, do not publish partial objects/messages; release owned staging and quotas exactly once. A streaming writer may already have emitted bytes on I/O failure; poison/abort frame or connection as appropriate, never promise wire rollback. HTTP content type and TCP frame limits bind the codec; TCP reads handle partial frames and reject trailing payload bytes. Never derive transport authorization from decoded DATA; CONTROL stays sealed and route generation is rechecked at publication.

## Qualification matrix
For each Java/Graal native image, LLVM AOT, .NET NativeAOT, Rust native, Wasm standalone/browser, Forge, Cranelift and JS target:
1. Compile and execute actual .atto typed roundtrips for struct, class, enum/ADT, nested generic and a closed interface/trait case; record which types are rejected or unimplemented.
2. Compare shared exact JSON/MessagePack bytes under a pinned canonical profile and all producer/consumer pairs. Test stable schema versions and explicit codec mismatch.
3. Compile-fail raw pointer/capability, borrowed mutable, unsupported cycles, missing generic proof and unregistered subtype. Runtime denial: duplicate keys, invalid UTF-8, truncated/oversized frames, depth/work limits, invalid tags, constructor invariant violation, stale generation and cancellation.
4. Verify local actor send does not invoke wire codec where ownership proof permits; test copy independence, sender invalidation and receiver heap lifetime. Test HTTP content type and partial TCP frames under backpressure. Instrument allocations/copies, report physical vs logical quotas separately.
5. Pin compiler revision, exact source root tree, case/corpus hashes, actual nonempty job steps and per-case results; separate host reference from guest compilation and execution, AOT evidence from JIT. Independent review required. Zero-job/zero-step runs are not evidence. An authorized private alternate-org exact-tree mirror may run tests without cross-org checkout tokens; do not publish source outside authorized visibility. No production support mask changes until these gates pass.
