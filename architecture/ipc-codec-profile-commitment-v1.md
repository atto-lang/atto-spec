# Opt-in IPC codec profile commitment — candidate v1

Status: HOST_REFERENCE_ONLY, pending normative review. Companion to #229 and https://github.com/atto-lang/atto-source.java/pull/1815. This is not a new DATA envelope, guest syntax, or a reinterpretation of legacy codec hashes.

A new opt-in profile commits to the exact codec label (messagepack, protobuf, cbor or flatbuffers), positive u32 decimal wire version, printable ASCII schema ID (1..256 bytes, no spaces), lower-case 64-hex shape digest, and lower-case 64-hex message ABI digest. The preimage is ASCII lines, each ending in LF (including the last): domain string atto.ipc.codec-profile.v1, codec, version, schema, shape digest, ABI digest. SHA-256 lower-case hex. The trusted build attestation must identify this exact commitment as its wire codec digest and independently bind message ABI. Existing authenticated READY commitments retain their semantics; legacy artifacts must not be silently interpreted as this profile. A separately trusted runtime registry supplies policy and verified decoder availability; mask values 1,2,4,8 are host metadata only, not wire identifiers. Neither an attestation nor a supported mask is proof of actual guest support.

Runtime verifies before publication and before bootstrap; immutable profile follows owned DATA delivery. Incoming payload cannot select codec. Receiver must still verify codec-specific schema and bounded decode, route identity and actual generation under actor mailbox lifecycle and supervisor escrow permit. Never treat an authenticated worker as an authorized arbitrary actor sender. No DATA authority over CONTROL. No implicit fallback. Route epoch watermark is runtime-local; retain retired identities bounded and fail closed on exhaustion. Durable or cross-runtime authority requires independent registry proof; no eviction-induced stale acceptance.

Example vector: messagepack, 2, order.v1, shape 11 repeated 32 times, ABI 22 repeated 32 times. Commitment 4315f8e976accccee7c327178d5b1b78d22cc97236be95dc02e9de9b8e541950. Host helper was executed at Java commit 9ca0825f4161a50f7a578cee98de99aaa1ad8566; not evidence of guest execution, cross-backend parity or full-tree CI.
