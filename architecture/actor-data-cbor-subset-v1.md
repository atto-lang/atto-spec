# Actor DATA CBOR initial deterministic subset — candidate v1

Status: HOST_REFERENCE_ONLY. Companion to https://github.com/atto-lang/atto-serialization-and-validation/pull/38. No guest syntax, no new wire envelope, no general CBOR claim. This subset follows existing signed-i64/finite-f64/bool/UTF-8/sequence shape capabilities. Require a pre-registered exact codec, version, schema and shape commitment before a future typed decoder admits the payload. The current preflight validates bytes, not their correspondence to a trusted shape.

Admit definite-length arrays and UTF-8 text, canonical shortest integer and length representations, signed i64 in both directions, bool, and finite binary64 only. Binary64-only is a deliberate profile restriction, not RFC 8949 preferred shortest float encoding. Reject binary16/32, maps (including duplicate keys), tags, byte strings, null/undefined, indefinite lengths, other simple values, trailing bytes, nonfinite numbers, malformed UTF-8 and out-of-range signed integers. No implicit fallback to another codec. Map/ADT/record extension requires explicit normative decisions.

Host reference charges 32 logical expanded bytes per node, 8 per array element, 4 per UTF-8 byte; work is bytes consumed plus nodes plus UTF-8 bytes validated. These are logical budget units, not physical heap bytes. Bound wire <= 1 MiB, expanded <= 8 MiB, nodes/elements <= 100000, work <= 4 MiB, depth <= 64 with root depth zero. Reject before materialization; one immutable owned input is required through preflight and later decode. No reparse under fresh unshared limits, no retained value release until receiver ownership transfer. Production runtime must account transient work, retained values, actual heap, mailbox and tenant concurrency. Host validator uses no dynamic allocation and a bounded recursive stack. All typed shape matching and compiler-generated guests remain outstanding.

## Typed host extension (candidate)

PR https://github.com/atto-lang/atto-serialization-and-validation/pull/39 uses the same reader in one pass with a trusted borrowed scalar or homogeneous-list shape. Charge additional work for text copy (one per byte) and array element writes (one per item) before allocation. Check the wire kind against the registered shape before materializing; no partial result on any error. This is not an attested runtime binding or a guest codec. Do not separately preflight then reset budgets.
