# Historical language-spec repository migration disposition

The November 8 proposal originated in `ores-truffle-oreslang/attolang-language-spec.md`. The current canonical repository is [atto-lang/atto-spec](https://github.com/atto-lang/atto-spec); see [its scope](../README.md). The legacy proposal's proposed destination is historical, not a current transfer instruction. Compiler implementations belong in atto-source.*, conformance in [atto-platform-conformance](https://github.com/atto-lang/atto-platform-conformance), and independently governed cloud infrastructure in [atto-co](https://github.com/atto-co). Historical .ores and package/CLI identifiers retain explicitly versioned compatibility where supported.

No new transfer, export, archive or permissions change is authorized here. Any future migration requires documented source/destination identities, exact SHA/tree, PRs/issues/tags, consumers/packages/Pages, Actions/billing, rules, secrets/apps/webhooks, independent authorization and rollback; verify post-transfer identity and restore controls before exact-head validation. Zero-step CI is not executed and host-only tests do not establish guest parity. Historical coordination: [migration issue](https://github.com/ores-truffle-oreslang/.github/issues/26).
